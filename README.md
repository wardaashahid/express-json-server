# Express JSON Server

A simple backend server built with Node.js and Express that demonstrates the request-response cycle using two JSON endpoints.

## Installation

```bash
npm install
```

## Run the server

```bash
node server.js
```

## Endpoints

### GET /

Returns:

```json
{
  "message": "Hello, World!"
}
```

### GET /about

Returns:

```json
{
  "name": "Warda",
  "course": "Backend Assignment"
}
```
